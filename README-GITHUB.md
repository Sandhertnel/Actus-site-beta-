# Actus Intermediações — Landing Page

Landing page React + Vite da Actus Intermediações. O pacote inclui os assets locais usados no hero e na seção de destaque.

## Executar localmente

```bash
pnpm install
pnpm dev
```

Para gerar a versão de produção:

```bash
pnpm check
pnpm build
```

O site usa os links oficiais do WhatsApp, grupo e Instagram já configurados no código.
